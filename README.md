# GEN MONITOR

ガスエンジンコージェネレーション設備の点検時期を管理するツールです。

**このリポジトリに業務データは含まれていません。**
公開しているのはツールのプログラム（HTMLファイル1個）とこの説明書きのみで、
お客様情報・点検履歴・受電データ・メーカー別の点検周期は一切含まれません。

---

## 何ができるか

- 運転時間から次回点検時期を予測
- 前回実施からの間隔を管理し、消耗品の交換周期を超えないよう実施時期を提案
- 時期基準の点検管理（保安検査、シーズンイン/オフ、補機の整備周期など）
- 受電・発電の1時間値を取り込み、点検で機器を停止した際の受電電力を試算
- お客様提出用の点検計画書を出力

## 使い方

https://t1ec9h-ctrl.github.io/gen-monitor/ をブラウザ（Chrome / Edge）で開くだけです。
インストールは不要です。HTMLファイルをダウンロードしてローカルで開いても同じように動作します。

初回は設定タブから点検サイクルの定義ファイルを読み込んでください（別途配布）。

## データの取り扱い

- **操作中の外部通信はありません。** グラフ描画などの部品はすべてHTMLに埋め込み済みで、
  Webフォントの外部読み込みも行いません。
  URLで開く場合はページ読み込み時にGitHubからHTMLを受け取る通信が1回発生しますが、
  その後の操作では通信が発生しません（F12 → ネットワークタブで確認できます）。
  HTMLをダウンロードしてローカルで開けば、読み込み時も含めて通信はゼロになります。
- **サーバーがありません。** データの送信先が存在しません。
- **データの保存先は利用者のPC内のみです。** 利用者が指定したJSONファイル、
  ブラウザのlocalStorage、および復旧用スナップショット（IndexedDB・最大6世代）に
  保存されます。いずれもPC内に留まり、外部に送信されません。
  ブラウザの保存領域はアクセス元のアドレスごとに分離されるため、他サイトからは参照できません。
  暗号化はされないため、PCのログイン管理が前提です。
- **メーカー別の点検周期はプログラムに含みません。** 別ファイルとして配布し、
  利用者が読み込む方式です。

アプリ内の「データ管理 → データの取り扱いを確認 / 印刷」から、
保存場所・確認手順・運用上の注意をまとめた資料を出力できます。

## 技術構成

単一HTMLファイル。外部依存なし。

- Vanilla JavaScript
- Chart.js 4.4.0（インライン埋め込み）
- Tailwind CSS 3.4（使用クラスのみ抽出しインライン埋め込み）
- Papa Parse 5.4.1（インライン埋め込み）
- File System Access API（ローカルファイルとの同期）
